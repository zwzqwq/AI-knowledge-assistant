# 参数速查目录（总索引）

> 本目录按**功能实现**分子目录，每个子目录记录一次功能的：**架构 + 各源文件参数**。
> 阅读代码时查"这个参数是干嘛的"，复习时扫一眼"这个功能有哪些文件、每个文件吃了哪些参数、调哪个影响什么"。
> 与 `config.py` 的关系：**config 是全局默认值，源文件通过 `config.XXX` 读取；构造参数是调用方传入，覆盖默认值。**

## 每个功能子目录的固定结构

```
功能名/
├── 架构.md                  # 本次功能架构图 + 文件职责 + 数据流 + 依赖
├── 01-源文件.md             # 按实现顺序：构造参数 / 读取的 config / 关键方法参数
├── 02-源文件.md
└── ...
```

每个文件页的固定结构（双轨格式）：
- **构造参数**：`__init__(...)` 接收什么，默认值，谁传入
- **读取的 config**：这个文件消费了哪些全局参数
- **关键方法参数**：核心方法的入参和返回
- 每个参数**大白话 / 技术性**双轨解释

## 更新规则

- 新功能实现 → 新建子目录（`功能名/`），内放 `架构.md` + 各文件页，本索引登记
- 新文件落地（如 ensemble.py）→ 子目录内新增编号文件，架构.md 状态改 ✅
- 新增参数 → 补进对应文件页 + 该功能 `config.py.md` 总表
- 改参数默认值 → 改 `config.py` + 同步对应页
